# Getting started

Two steps from nothing to a notebook you can share.

- [Install](install.md): get the extension into DuckDB 2.0.1, from CI or from source.
- [Your first notebook](first-notebook.md): write a three-cell notebook, open it in the editor, run
  it, save it, export it and run it headless, in about five minutes.

Then pick a [guide](../guides/index.md) for what you want to do next.
